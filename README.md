# Fleck

Fleck is an open-source, no-telemetry macOS utility CLI with four cautious modules: Clean, Uninstall, Duplicates, and Ports & Procs. It uses a shared allow-list safety policy and Finder-compatible Trash moves.

## Install

```sh
brew install fleck
```

Source repository: https://github.com/yanaalvasiu/fleck

## Safety model

Every candidate is previewed before action. `--dry-run` prints the plan and exits; non-interactive use requires `--yes`. Items go to `~/.Trash`, never directly to permanent deletion. Paths are resolved immediately before acting, must be below configured roots, and are refused if protected, whitelisted, symlink-escaped, root, or the home directory itself. The process module refuses PID 1 and should be extended with macOS-specific guardrails before release.

If Clean or Uninstall finds a selected item that is not user-writable, it prints the affected count and asks whether to continue with `sudo` or skip those items. Elevation is requested only for those specific items; dry-run and JSON modes never prompt.

All tests use temporary directories and spawned fixtures. No telemetry is collected. The only intended network request is the GitHub Releases latest endpoint, cached for 24 hours and skipped in CI, JSON mode, non-TTY mode, or when disabled.

## Commands

```text
fleck clean [--dry-run] [--yes] [--json]
fleck uninstall [--orphans] [--dry-run] [--yes] [--json]
fleck duplicates [PATH] [--dry-run] [--yes] [--json]
fleck ports [PORT]
fleck ports free PORT [--yes]
fleck procs [SEARCH] [--watch]
fleck history [--json]
fleck update
fleck version
```

Shell completion is generated by the release build with the command framework selected by the final concrete project name. Current implementation uses the Go standard library to minimize attack surface and avoid cgo; cobra, Bubble Tea, gopsutil, BLAKE3, image hashing, and SQLite are deliberately not runtime dependencies until their macOS behavior is covered by fixtures. If introduced, pin versions and verify their licenses in CI.

## Development

```sh
go test -race ./...
go vet ./...
```

The CI workflow runs tests, lint, and a dependency-license gate on every pull request. Releases target macOS 12+ on amd64 and arm64.
